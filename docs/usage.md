# NightwatchMIDI — 守夜人口琴 MIDI 播放器

Python **3.11** + PySide6 + mido。通过标准 Win32 SendInput 在游戏口琴中演奏 MIDI；保留 Phase 0 输入测试器。版本 0.4.0。

## 启动

首次安装：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m nightwatch_midi
```

已有环境直接执行最后一行，或双击 `start.cmd`（使用 `pythonw`，不会出现控制台窗口）；需要查看日志时双击 `start-debug.cmd`。若游戏以提升权限运行，需要用户自行以匹配权限启动本软件。在项目目录的 PowerShell 中可以执行：

```powershell
Start-Process -Verb RunAs -FilePath "$PWD\.venv\Scripts\python.exe" -ArgumentList "-m nightwatch_midi"
```

Windows 会要求确认。软件不会自行提权，每次启动真实输入默认关闭。选谱统一通过「选择 MIDI 文件」按钮，不依赖拖放，因此管理员运行也不影响导入。

## 演奏一首歌

1. 点击「♪ 选择 MIDI 文件」选择 `.mid` / `.midi`（系统文件对话框，仅过滤这两种格式）。软件自动推荐旋律并适配音域，并在「乐谱」卡片给出分析与优化建议；首次导入会询问是否加入曲库，加入后可在「曲库」分页搜索、收藏、双击换曲。
2. 按需点击“一键优化”，或直接选一个演奏预设（平衡 / 稳定 / 高还原 / 高速）。预设把时序与编排参数打包，一键写入；之后仍可在高级设置微调。
3. 选择“游戏演奏模式”，点击“开始演奏”，在默认 5 秒倒计时内切回游戏口琴界面。
4. 游戏中可用全局快捷键 F9 后退 10 秒、F10 前进 10 秒、F8 从设定位置重播；F12 或点击停止释放输入。播完、停止后自动回到“预览模式”；下次游戏演奏需再次主动选择模式。

默认“预览模式”只显示进度，**不会发声，也不会控制游戏**。首次可选 `examples/小星星.mid`：《小星星》，42 音符、24 秒。播放期间保持游戏窗口在前台；切换到其他窗口会停止。

界面为现代卡片式：极浅灰背景 + 白色圆角卡片（阴影、统一 8px 圆角、按钮有 Hover/按下反馈），主按钮品牌蓝实色、信息灰字、停止红色。顶部右侧「乐器名 ▼」是可点击下拉（可导入其他乐器配置），设置收成最右的齿轮图标。主界面分「演奏 / 曲库 / 谱曲 / 高级设置」四个分页：演奏页是自上而下的信息流 **乐谱 → 参数 → 播放器**。「乐谱」卡片左侧是文件选择（「♪ 选择 MIDI 文件」；未选择时灰字“尚未选择乐谱”），右侧是「时长 / 原谱 BPM / 音符」横向键值面板（未加载用 `--` 占位），一键优化在未选曲时置灰、选曲后以蓝框高亮；下方是两行分析与建议。「参数」卡片是单选式预设（平衡 / 稳定 / 高还原 / 高速，默认选中平衡）与三列对齐的音域/速度/倒计时，长说明收进「?」悬浮提示。「播放器」卡片含演奏方式、进度区、`<< / >>` 跳转与加粗可拖起点滑块，以及全宽「开始演奏」与最右红色「紧急停止 · F12」。点击开始后进度区中央显示巨大倒计时数字。底部浅蓝色指引条常驻：“1. 点击选择乐谱 → 2. 选择预设与演奏方式 → 3. 点击「开始演奏」”。曲库页可搜索、只看收藏、按名称/最近播放/加入时间排序；谱曲页可粘贴按键谱/简谱并生成演奏或存入曲库；高级设置页四组参数保留逐项小字说明。窗口底部为常驻的红色免责声明条，点击查看完整文本；再下方是跨分页的浅蓝状态指引条。主界面无需滚动，播放期间曲库、谱曲与高级设置分页不可切换。

“设置 → 乐器”导入 JSON 配置；“设置 → 高级 → 输入测试”进行原有按键及鼠标测试。打开设置、进入或退出输入测试均会释放输入，防止两个界面同时控制游戏。诊断内容也位于设置的高级页。

暂停能力仍未接入：播放时“暂停（暂不可用）”按钮保持禁用。但可拖动进度滑块设定播放起点，或用 F9/F10/「<< / >>」跳转重播；停止后保留停止位置，再次点击即可从该处继续。全局快捷键默认开启，可在「高级设置 → 输入与安全」关闭；按键仍会传给游戏，请先确认 F8/F9/F10 与游戏功能不冲突。

“一键优化”不会自动降速，但移调、折回与复音取舍仍属于改编，并非无损还原原曲。主动选择高级设置的“自动降速”仍可改变速度；**0.6x 会把 120 BPM 改为 72 BPM**。原谱 BPM 不受速度设置影响。需要对照原 MIDI 时，可在“高级设置 → 演奏方式”点击“恢复原谱节奏”，恢复 1x、不合并相近起音、不顺延、保留开头空白；要同时保留原音高，选择“原始”音域。旋律推荐仅为估计，可在高级设置中更换声部。

进阶：在「谱曲」分页可直接粘贴网上的按键谱或简谱文本，解析后「生成并演奏」或「保存到曲库」。按键谱按当前乐器配置的键名解析（`Z X C V B N M`，`[60]` 指定音高，`Z+X` 同时按下）；简谱支持 `1-7`、`0` 休止、`#`/`b` 变音、`'`/`,` 八度、`-` `.` `/` 时值、`[1 3 5]` 和弦，以及 `BPM`、`1=C`、`4/4` 指令行。按键谱没有无鼠标组合的键位时按最近音高处理并给出提示；中文曲名写入 MIDI 内部轨道名时会回退为 ASCII，曲库标题仍保留中文。

另附 `tests/fixtures/chromatic_48_85.mid`：全部 38 个音高的半音阶，19 秒，用于手动核对鼠标组合与音高。生成脚本为 `tools/create_demo.py`。

## 已实现

- MIDI Type 0 / 1，多轨全局速度变化，note_on velocity=0 视作 note_off；支持 CC64 延音踏板、CC120/123/121 的基本释放语义。
- 音轨／通道选择、鼓通道排除、-48 到 +48 半音移调、八度折回或跳过、0.25–2 倍速。
- 按起音归组选最高音，默认归组窗口 0 ms，只合并同时开始的音；可设为 30 ms 适配略微错开的钢琴和弦，但会改变部分起音。选旋律优先于八度折回，不会让折回后的低音抢走原高声部。被压掉或截断的旧音不再重弹。
- 兼容和弦为实验选项：只同时保留相同鼠标组合、不同键位的音符，游戏实际复音能力未经验证。
- 稳健档默认：变调提前 40 ms，最短按住 50 ms，松键间隔 40 ms，松键到鼠标切换至少 15 ms。标准档为 25/35/25/10 ms；快速档为 15/25/15/5 ms。所有时序余量均为物理时间，**不随倍速压缩**。可单独修改分音间隔。
- 键盘先松开，经过尾部余量才切换鼠标，再等变调提前量后按下音键；相邻音鼠标组合相同则保留鼠标状态。第一音同样有准备时间。
- 原谱节奏（默认）：编排中保留各音符原始起音位置，无法满足键鼠间隔的音符计入“过密跳过”，不顺延。兼容的节奏优先模式允许最多 60 ms 顺延；音符优先模式保留已选择的旋律/和弦，必要时排队，可能延长整曲。各模式都显示实际编排音数、过密跳过、最大顺延与预计时长。
- “自动降速”尝试当前速度至 0.25 倍，优先找到没有过密跳过的较快速度，否则选跳过最少者。它不恢复已做复音简化的声部，且可能显著放慢歌曲，可手动改回。
- 谱曲分页：`score.py` 把按键谱与简谱文本解析为时值时间轴并生成 MIDI，复用现有解析、编排与播放管线；支持解析预览、生成并演奏、保存到曲库（曲名可编辑），谱内指令会覆盖界面上的速度/调号/拍号设置。
- 曲库分页：导入后可在界面内选择把 MIDI 副本存入本机曲库。列表每行显示收藏星标、曲名，以及时长 / 音符 / 原谱 BPM / 播放次数 / 最近播放，并带「已优化」徽标；点星标即可收藏，双击或点「载入所选曲目」换曲。顶栏支持按曲名搜索、只看收藏、按名称/最近播放/加入时间排序、「打开文件夹」与「＋ 从文件导入」；空库或筛选无结果时显示引导提示；底部显示选中曲目的优化详情（移调/折回/跳过/速度）并可「移出曲库」。默认目录为 `%APPDATA%\NightwatchMIDI\library`，可用环境变量 `NIGHTWATCH_MIDI_HOME` 重定向；曲库只做文件复制与索引，不参与解析和播放调度。原文件移动或删除不影响曲库副本。
- 演奏预设：平衡 / 稳定 / 高还原 / 高速四个按钮，把时序档、起音归组、密集策略、音域与速度组合成日常选择；手动改动任一相关参数后预设自动取消，避免显示与实际不符。
- Seek：进度滑块可设定播放起点（按钮显示「从 00:12 开始演奏」），「<< / >>」与全局 F9/F10 可在播放中立即跳转重播；Seek 会丢弃截断处未弹完的音符，并自动补回仍然按住的鼠标组合，不会向游戏发送无配对的松开。
- 全局快捷键：F8 从当前起点重播（带倒计时）、F9/F10 快退/快进 10 秒、F12 停止，游戏前台时通过轮询按键状态触发，不注入、不挂钩；可在高级设置中关闭。
- 播放进度、倒计时、完成/错误状态。停止后保留位置，可再次从该处开始；当前不提供暂停、A-B 循环。
- 工作线程独占输入后端，以 `time.perf_counter()` + 绝对截止时间调度，通过可取消的 `threading.Event.wait()` 等待，绝不通过连续 sleep 累积播放时间。
- 编译时已应用倍速，播放器不重复缩放。运行中还按实际发出时间保护最短按住／变调／松键间隔；系统卡顿造成落后超过 250 ms 则停止，避免把错过的输入挤在一起补发。
- 全局速度图和拍号图分别保留：速度用于 ticks 到秒，拍号用于小节／拍位。4/4 变成 2/4 不会让音符自动快一倍。BPM 明确按四分音符标注；6/8 的拍位按八分音符计数，不把每个八分音符误作四分音符。
- 拍位从文件起点的小节 1 计数，拍号变化若发生在小节中间则按新小节显示；MIDI 缺乏弱起小节编号约定时不能自动推断谱面原编号。缺少元数据时明确标注默认 120 BPM / 4/4。顺延模式只显示最近实际起音对应的原谱拍位，避免把已拉长的时间误报为原节拍进度。
- 倒计时结束时记录前台窗口、双方完整性级别。若目标仍是本软件或目标权限高于测试器，则停止。播放时每次事件及等待循环检查前台窗口，最长等待片段 20 ms；窗口变化后停止。该检查不是系统级原子操作，仍存在检查与发送之间的极短竞争窗口。
- 默认 Mock；真实输入使用 ctypes 调用标准 SendInput，键盘为扫描码方式。

## Instrument Profile

`src/nightwatch_midi/profiles/delta_harmonica.json` 按用户提供的 `键位对照表` 逐项录入。音高、键位、鼠标组合全由 JSON 提供。`input_tester.json` 供原输入测试页使用。

示例结构：

```json
{
  "name": "Example",
  "keys": {"Z": 90},
  "mouse_buttons": ["left", "middle", "right"],
  "midi_notes": {
    "60": "Z",
    "49": {"key": "Z", "buttons": ["left", "middle"]}
  }
}
```

数字键名为 MIDI 音高。值可为单个键名，或带 `key` 和 `buttons` 的对象。解析器只处理 MIDI 数据，调度器只执行编译后的输入动作，均不包含游戏键位。界面支持载入其他 JSON Profile。

## 边界与释放

这是单件游戏乐器的基础改编播放器，不保证还原完整多乐器编曲。音色、力度、弯音、触后及多数控制器无法用现有游戏按键表达；不支持 SMPTE 时间格式和 Type 2 异步文件。兼容和弦在游戏内的实际发声能力仍需手动验证，默认使用单音模式。

停止、取消、异常、正常退出和可处理的退出信号都会进入 `release_all()`。所有输入线程结束后才允许 UI 重试释放或更换后端，避免释放与按下并发。释放失败时保留后端、禁用新播放，允许再次点击 Emergency Stop。切换两个功能页也会停止并关闭真实输入。

强制终止进程、断电、系统拒绝输入等情况下无法保证释放成功。桌面调度也不是硬实时。

不注入 DLL、不读取或写入游戏内存、不安装驱动、不绕过反作弊。诊断只读取窗口和访问令牌元数据。SendInput 调用成功表示事件进入 Windows 输入流，不表示游戏一定处理。
